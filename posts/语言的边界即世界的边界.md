对个人博客做一个简要的说明。

其实很早就萌生了“做一个属于自己的博客”这个想法。  
大概两年前那会儿，还是大学，凭借着浅薄的知识与爱折腾的干劲，重复造轮子，手搓了个博客项目。可惜完美主义作祟，无论怎么写都看不对眼。心中仍留不满。后遂不了了之。  
该博客属于峥嵘岁月的某种纪念，或是折腾不息精神的死灰复燃。  

# 技术说明

开发主要依赖许愿式的自然语言编程。

## 框架构建

项目依托前端技术栈，使用 `vite` 进行项目的开发、测试与打包。  

框架选用 [`solid-js`](https://www.solidjs.com/)，一个更加现代的前端框架。SolidJS 在保留了 React 式的 JSX 开发体验的同时，抛弃了其虚拟 DOM 与重渲染的更新方案，理论更轻量、性能更加优异。相较于烂大街的主流权威，SolidJS 更像是个小众变态选项。不过这也正是我选择它的理由。  
路由 `@solidjs/router`，官方自备。

## 文章渲染

博文仅支持 Markdown 格式。

引入 `gray-matter`，支持解析文件的头部元数据（Front-Matter）部分。支持以下的字段：

```
title: string
date created: dddd, MMMM Do YYYY, h:mm:ss a
date modified: dddd, MMMM Do YYYY, h:mm:ss a
category: string
```

所有字段均为可选。`title` 缺失时，使用不含 `.md` 的文件名作为文章标题。`date` 字段使用 Obisidian 的 Linter 插件自动生成。对于分类，可以直接将文件丢到子文件夹，使用子文件夹名作为分类名。
